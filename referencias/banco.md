# 🗄️ Esquema de Dados e Tabelas (PostgreSQL / Supabase) — Portal Escola Elza

Este documento define a especificação oficial de dados para o **Portal Escola Elza**. Ele serve de referência tanto para as classes `Model` em JavaScript (que utilizam temporariamente o `localStorage` para testes) quanto para a estrutura definitiva no **Supabase (PostgreSQL)**.

---

## ⚙️ Regras Gerais e Padrão de Campos

- **Banco de Dados Alvo:** PostgreSQL (Supabase)
- **Armazenamento Temporário (Front-end):** `localStorage` (chaves: `elza_users`, `elza_suggestions`, `elza_articles`, `elza_events`, etc.)
- **Convenção de Tipos PostgreSQL:**
  - `BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`: Chaves primárias auto-incrementáveis.
  - `VARCHAR(n)` / `TEXT`: Strings, textos longos, e-mails, URLs e JSONs.
  - `BOOLEAN`: Boleanos reais (`TRUE` ou `FALSE`).
  - `TIMESTAMPTZ`: Datas e horários com fuso horário (`DEFAULT NOW()`).

---

## 🚀 FASE 1: Esquema Mínimo (MVP Inicial)

### 1. `users` (Usuários e Autenticação)
```sql
CREATE TABLE IF NOT EXISTS users (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nome VARCHAR(150) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  senha_hash TEXT NOT NULL,
  perfil VARCHAR(50) DEFAULT 'estudante', -- 'estudante', 'professor', 'coordenador', 'diretor', 'admin'
  matricula VARCHAR(50),
  serie VARCHAR(20),
  turma VARCHAR(20),
  telefone VARCHAR(30),
  ativo BOOLEAN DEFAULT TRUE,
  ultimo_login_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  deleted_at TIMESTAMPTZ
);

2. suggestions (Sugestões e Ouvidoria)

CREATE TABLE IF NOT EXISTS suggestions (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  anonimo BOOLEAN DEFAULT FALSE,
  nome VARCHAR(150),
  email VARCHAR(255),
  perfil VARCHAR(50), -- 'estudante', 'professor', 'responsavel', 'comunidade'
  categoria VARCHAR(100), -- 'infraestrutura', 'projeto', 'convivencia', 'elogio', 'outro'
  titulo VARCHAR(255) NOT NULL,
  mensagem TEXT NOT NULL,
  status VARCHAR(50) DEFAULT 'recebido', -- 'recebido', 'em_analise', 'respondido', 'arquivado'
  responsavel_id BIGINT REFERENCES users(id),
  resposta TEXT,
  respondido_at TIMESTAMPTZ,
  ip_hash VARCHAR(255),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  deleted_at TIMESTAMPTZ
);

3. articles (Notícias e Publicações)

CREATE TABLE IF NOT EXISTS articles (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  author_id BIGINT REFERENCES users(id),
  autor_nome VARCHAR(150) NOT NULL,
  categoria VARCHAR(100) NOT NULL, -- 'noticia_geral', 'artigo_cientifico', 'ser_onu', 'cultura_afro'
  titulo VARCHAR(255) NOT NULL,
  slug VARCHAR(255) UNIQUE,
  resumo TEXT NOT NULL,
  conteudo TEXT NOT NULL,
  imagem_url TEXT,
  status VARCHAR(50) DEFAULT 'aguardando_coordenacao', -- 'rascunho', 'aguardando_coordenacao', 'em_revisao', 'aprovado', 'publicado', 'recusado'
  motivo_recusa TEXT,
  featured BOOLEAN DEFAULT FALSE,
  published_at TIMESTAMPTZ,
  published_by BIGINT REFERENCES users(id),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  deleted_at TIMESTAMPTZ
);

4. media_files (Gerenciamento de Mídia / Supabase Storage)
CREATE TABLE IF NOT EXISTS media_files (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  owner_id BIGINT REFERENCES users(id),
  file_name VARCHAR(255) NOT NULL,
  original_name VARCHAR(255) NOT NULL,
  storage_path TEXT NOT NULL,
  public_url TEXT NOT NULL,
  mime_type VARCHAR(100) NOT NULL,
  size_bytes BIGINT NOT NULL,
  alt_text VARCHAR(255),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  deleted_at TIMESTAMPTZ
);

5. events (Agenda e Eventos)
CREATE TABLE IF NOT EXISTS events (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  categoria VARCHAR(100), -- 'neaonnim', 'ser_onu', 'vozes_negras', 'conselho', 'outros'
  titulo VARCHAR(255) NOT NULL,
  slug VARCHAR(255) UNIQUE,
  descricao TEXT,
  data_inicio TIMESTAMPTZ NOT NULL,
  data_fim TIMESTAMPTZ,
  local VARCHAR(255) NOT NULL,
  imagem_id BIGINT REFERENCES media_files(id),
  inscricao_aberta BOOLEAN DEFAULT FALSE,
  inscricao_url TEXT,
  status VARCHAR(50) DEFAULT 'publicado',
  created_by BIGINT REFERENCES users(id),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  deleted_at TIMESTAMPTZ
);

6. audit_logs (Logs de Auditoria)
CREATE TABLE IF NOT EXISTS audit_logs (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id BIGINT REFERENCES users(id),
  acao VARCHAR(100) NOT NULL, -- ex: 'login', 'aprovou_noticia', 'deletou_evento'
  entidade VARCHAR(100) NOT NULL, -- ex: 'articles', 'users'
  entidade_id BIGINT,
  dados_novos TEXT,
  ip_hash VARCHAR(255),
  created_at TIMESTAMPTZ DEFAULT NOW()
);
